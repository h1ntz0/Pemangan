# Antigravity Agent Guidelines: Autonomous Mode & Full Access

## 1. Autonomous Execution & Full Authorization
- **Auto-Accept & Full Permission**: You are granted full access, full change permissions, and autonomous execution authority across the entire workspace.
- **Proactive Implementation**: Never ask for confirmation before making standard code edits, running terminal commands, creating files, or refactoring. Proceed immediately with direct execution.
- **Continuous Resolution**: Implement complete, production-grade solutions end-to-end. Do not leave placeholders or TODOs.
- **Automatic Verification**: Whenever changes are made, automatically verify and test them (using test runners, code graph, terminal commands, or browser verification) without waiting for user intervention.

## 2. Code Quality & Standards
- Maintain clean code, preserve docstrings/comments where appropriate, and adhere to project architecture.
- Ensure all MCP servers, scripts, and skills remain error-free.

# Workspace Directive: Full Access & Autonomous Execution

- **Autonomous Authority**: Full permission is granted to perform all file modifications, creations, deletions, refactoring, and terminal executions proactively.
- **No Unnecessary Prompts**: Do not prompt or pause for approval on standard development actions. Implement and test directly.
- **Full Scope Change**: Full change access across all workspace components (source files, assets, `.agents` configs, skills, and MCP servers).
